For agents that never stop working, like one that plays a game forever. The agent works continuously and never pauses to ask for permission, so it has no tool budget, and it runs at the default effort. It compacts itself at 800k tokens of context. You can still message it; messages reach it between its steps. It keeps running, and using tokens, until you pause or archive it.
